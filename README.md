# 마인드원 컨설턴트 (customer-care)

지자체 방문 영업용 모바일 웹앱. 종이 서식 두 가지를 그대로 휴대폰에 옮기고, 상담 녹취를 올리면 그 양식에 자동으로 채워 넣는다.

- **고객 방문 질문지 v1.0** : 방문 개요 · 사전 확인 · 질문 19개(A~E) · 마무리 확인
- **상담일지 v1.1** : 사이트 개요 · 담당자 카드 · 상담 누적 기록(고객 난제 포함) · 후속 조치 · 제안/계약 메모

설치 없이 브라우저에서 쓰고, 홈 화면에 추가하면 앱처럼 열린다. 데이터는 **기기 안에만** 저장된다(서버 없음).

---

## 1. 화면

| 화면 | 하는 일 |
|---|---|
| 사이트 | 지자체 목록. 후속 조치와 고객 난제 건수를 배지로 표시 |
| 사이트 상세 | 상담일지 전체. 담당자 카드, 상담 누적, 후속 조치, 제안 메모 |
| 방문 질문지 | 질문 19개에 답변 기록. 사이트마다 여러 건 누적 |
| 내보내기 | 두 화면 모두 한글(hwpx) · 텍스트 복사 · txt 저장 |
| 녹음 · 분석 | 현장 녹음, 음성 파일 업로드, 전사 텍스트 확인, AI 분석 후 양식에 반영 |
| 설정 | 회사 서버 · 동기화, API 키, 공유용 내보내기 · 합치기, 백업 |

## 2. 키 없이 쓰기 (기본)

API 키를 하나도 넣지 않아도 아래는 모두 된다. 비용도 들지 않는다.

| 기능 | 키 필요 | 방법 |
|---|---|---|
| 서식 입력 · 누적 | 없음 | 그냥 입력하면 기기에 저장 |
| 현장 녹음 | 없음 | 녹음 버튼. 안드로이드 크롬은 말이 자동으로 받아써진다 |
| 음성 보관 | 없음 | 「앱에 보관」을 누르면 기기 안에 저장, 목록에서 재생 · 내려받기 |
| 받아쓰기 (아이폰) | 없음 | 전사 칸을 누르고 **키보드의 마이크 버튼**으로 말하면 글로 들어간다 |
| 녹취 → 양식 정리 | 없음 | **「키 없이 정리 (무료)」** 버튼. 규칙으로 문장을 항목에 나눠 담는다 |
| 한글 · 텍스트 내보내기 | 없음 | 기기 안에서 파일 생성 |

「키 없이 정리」는 키워드 규칙으로 문장을 배정하는 방식이라 AI 분석보다 거칠다. 미리보기에서 확인하고 고친 뒤 반영하면 실무에는 충분하다.

### 팀 전체가 키 없이 AI 분석까지 쓰려면

휴대폰마다 키를 넣는 대신 **회사 서버를 한 번만** 만든다. `server/worker.js` 를 Cloudflare Workers(무료)에 올리고, 회사 키 하나와 팀 코드를 서버에 넣는다. 팀원은 앱 설정에 **서버 주소와 팀 코드만** 입력하면 된다.

```bash
npm i -g wrangler && wrangler login
wrangler deploy server/worker.js --name mindone-cc
wrangler secret put ANTHROPIC_API_KEY   # 회사 Claude 키
wrangler secret put TEAM_CODE           # 사내 공용 암구호
```

비용은 회사 계정 한 곳에 모이고, 사람이 바뀌어도 키를 다시 나눠줄 필요가 없다. 키가 새면 서버에서 한 번만 바꾸면 된다.

## 3. 녹취 자동 정리

```
현장 녹음(브라우저 실시간 받아쓰기)  ┐
음성 파일 업로드(Whisper 전사)       ├→ 전사 텍스트 → Claude 분석 → 미리보기 → 양식 반영
클로바노트 등 텍스트 붙여넣기        ┘
```

- **분석 결과는 바로 저장되지 않는다.** 항목별 미리보기를 보고 「이 내용으로 양식 채우기」를 눌러야 반영된다.
- 질문지 답변은 **비어 있는 칸만** 채운다. 직접 적은 내용은 덮어쓰지 않는다.
- 상담일지에는 누적 기록 1건이 새로 추가되고, 녹취에서 확인된 담당자와 후속 조치가 함께 등록된다.
- 녹취에 근거가 없는 항목은 비워 둔다. 지어내지 않도록 프롬프트에 명시되어 있다.

### 전사 방식별 지원

| 방식 | 지원 환경 | 키 필요 |
|---|---|---|
| 현장 녹음 + 실시간 받아쓰기 | 안드로이드 크롬, 데스크톱 크롬 · 엣지 | 없음 |
| 키보드 마이크로 받아쓰기 | 아이폰 · 안드로이드 모두 | 없음 |
| 음성 파일 업로드 전사 | 모든 환경 (Whisper API 호출) | OpenAI 키 |
| 텍스트 붙여넣기 | 모든 환경 | 없음 |

iOS 사파리는 실시간 받아쓰기를 지원하지 않는다. 녹음은 되므로 파일 전사나 붙여넣기를 쓴다.

## 4. 사용 준비

1. 앱 주소를 휴대폰에서 연다.
2. 브라우저 메뉴에서 **홈 화면에 추가**를 누르면 앱 아이콘이 생긴다.
3. 여기까지만 해도 입력 · 녹음 · 보관 · 「키 없이 정리」 · 한글 내보내기가 모두 된다.
4. (선택) AI 분석을 쓰려면 설정에 **회사 서버 주소 + 팀 코드**를 넣는다. 서버가 없으면 개인 Claude 키를 넣어도 된다.
5. (선택) 올린 음성 파일을 자동 전사하려면 **Whisper(OpenAI) 키**를 넣는다. 현장 녹음 받아쓰기와 키보드 받아쓰기는 키가 없어도 된다.

> 키는 그 기기의 브라우저 저장소에만 있고 어디로도 전송되지 않는다(호출 대상 API 제외). 공용 기기에서는 사용 후 설정에서 지운다.

## 5. 배포 (GitHub Pages)

`main` 브랜치에 올리면 Actions가 자동 배포한다.

1. 저장소 → Settings → Pages → Source 를 **GitHub Actions** 로 지정
2. push 하면 `https://<계정>.github.io/customer-care/` 로 열린다

빌드 도구가 없는 정적 파일이라 그대로 올라간다. 로컬에서 볼 때는 모듈 사용 때문에 파일을 직접 열지 말고 서버로 띄운다.

```bash
python -m http.server 8765
# http://localhost:8765
```

## 6. 한글(hwpx) 내보내기

상담일지와 질문지 화면 아래 **「한글 파일(hwpx) 내려받기」** 버튼을 누르면 회사 문서 서식 그대로 된 한글 파일이 바로 만들어진다. 서버를 거치지 않고 휴대폰 안에서 생성한다.

- 서식 : 제목 + `□` 소제목 + `○` 본문 + `―` 세부 + `※` 비고 (영덕 추진계획(안) 계열 서식)
- 원리 : `assets/form.hwpx`(스타일만 담긴 빈 서식)의 문단을 복제해 텍스트만 바꿔 넣고 다시 압축한다
- 이 템플릿에는 고객 내용이 들어 있지 않다. 스타일 정의와 자리표시자(`{{BOX}}` 등)만 있다
- 텍스트 복사 · 파일 저장(txt)도 그대로 쓸 수 있다

## 7. 여러 명이 함께 쓰기 (1단계 : 파일 주고받기)

서버 없이 백업 파일로 협업한다. 설정 화면에서 쓴다.

1. **공유용 내보내기** : 사이트와 방문 기록만 담긴 JSON 을 만든다. **API 키는 들어가지 않는다.**
2. 그 파일을 네이버웍스 · 메일 · 메신저로 동료에게 보낸다.
3. 받은 사람은 **받은 파일 합치기** 를 누른다.

합치기 규칙

- 같은 지자체는 **하나로 모은다.** 이름이 같으면 같은 사이트로 본다.
- 상담 기록 · 담당자 · 후속 조치는 **양쪽을 모두 살린다.** 같은 내용은 한 번만 남는다.
- 사이트 정보가 서로 다르면 **내 값이 우선**이고, 내가 비워 둔 칸만 상대 값으로 채운다.
- 질문지는 답변을 칸 단위로 합친다. 내가 적은 답은 덮어쓰지 않는다.
- **API 키는 가져오지 않는다.** 내 설정은 그대로 유지된다.
- 같은 파일을 두 번 합쳐도 늘어나지 않는다.

기기를 바꿀 때는 **전체 백업(키 포함) → 덮어쓰기 복원**을 쓴다. 이 파일은 키가 들어 있으므로 남에게 주지 않는다.

## 8. 여러 명이 함께 쓰기 (2단계 : 회사 서버 동기화)

회사 서버를 한 번 만들어 두면 파일을 주고받을 필요 없이 자동으로 합쳐진다. 팀원은 설정에 **주소 · 팀 코드 · 이름**만 넣는다.

### 동작 방식

```
기기에 먼저 저장  →  (통신될 때) 서버에서 받기 → 내 것과 합치기 → 내 것 올리기
```

- 앱을 열 때 자동으로 한 번, 사이트 목록의 **↻ 동기화** 버튼으로 언제든 수동 실행
- 통신이 안 되면 그냥 기기에만 저장된다. 현장에서 입력이 멈추지 않는다
- 상담 기록 · 담당자 · 후속 조치는 **양쪽을 모두 살린다.** 두 사람이 같은 사이트에 각각 적어도 둘 다 남는다
- 같은 항목을 둘이 고쳤으면 **나중에 고친 쪽**이 남는다
- 사이트나 질문지를 지우면 다른 기기에서도 지워진다(삭제 기록 전파)

### 배포 (한 번만)

```bash
npm i -g wrangler && wrangler login

wrangler d1 create mindone-cc
# 출력된 database_id 를 server/wrangler.toml 에 붙여 넣는다

wrangler d1 execute mindone-cc --remote --file server/schema.sql --config server/wrangler.toml
wrangler deploy --config server/wrangler.toml

wrangler secret put ANTHROPIC_API_KEY --config server/wrangler.toml   # 회사 Claude 키 (분석용)
wrangler secret put TEAM_CODE --config server/wrangler.toml           # 사내 공용 암구호
```

배포되면 `https://mindone-cc.<계정>.workers.dev` 주소가 나온다. 앱 **설정 → 회사 서버** 에 그 주소와 팀 코드를 넣고 **연결 확인**을 누르면 상태가 보인다.

### 서버가 하는 일

| 주소 | 하는 일 |
|---|---|
| `POST /analyze` | 회사 키로 녹취를 분석해 돌려준다 (휴대폰에 키 불필요) |
| `GET /sync?since=` | 그 시각 이후 바뀐 자료를 내려준다 |
| `POST /sync` | 내 자료를 올린다 (나중에 고친 쪽이 이김) |
| `GET /health` | 서버 · 저장소 · 분석 키 상태 확인 |

### 보안과 비용

- **팀 코드**를 모르면 어떤 요청도 받지 않는다. 코드가 새면 서버에서 한 번만 바꾸면 된다.
- `wrangler.toml` 의 `ALLOW_ORIGIN` 을 앱 주소로 지정하면 그 앱에서만 호출된다.
- 데이터는 회사 Cloudflare 계정 안에 있다. 외부 서비스에 고객 정보를 올리지 않는다.
- Workers 무료 한도는 하루 10만 요청, D1 무료 한도는 5GB 다. 이 규모에서는 비용이 들지 않는다.
- 녹음 파일은 서버로 보내지 않는다. 기기에만 보관한다.

> 1단계(파일 주고받기)는 그대로 쓸 수 있다. 서버를 쓰지 않는 사람과는 공유용 파일로 주고받으면 된다.

## 9. 데이터

- 저장 위치 : 브라우저 localStorage (`mindone.customercare.v1`)
- 기기를 바꾸거나 앱을 지우면 사라진다. **설정 → 백업 내보내기**로 JSON을 주기적으로 저장한다.
- 상담일지와 질문지는 각각 텍스트로 복사 · 저장할 수 있다. 한글 문서에 붙여 넣어 보고서로 쓴다.

## 12. 알려진 제약

- 오프라인에서 입력은 되지만 AI 분석과 파일 전사는 통신이 필요하다.
- 보관한 녹음은 기기 저장 공간을 쓴다. 설정에서 용량을 확인하고 오래된 것은 지운다.
- 동기화는 앱을 열 때와 버튼을 누를 때 일어난다. 상대가 입력하는 즉시 내 화면에 뜨지는 않는다.
- 녹음 파일은 동기화되지 않는다. 기기에만 남는다.
- 한글 파일은 표 없이 개조식 문단으로 출력된다. 종이 서식의 표 모양이 필요하면 내려받은 파일에서 직접 표로 정리한다.
